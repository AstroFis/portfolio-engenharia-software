## 💻 Projetos de Engenharia de Software no Portfólio (`./projetos/`)

1. **[`01-automatoforms-rpa-ia`](./projetos/01-automatoforms-rpa-ia)** — **AutomatoForms ("Jarvizinha"):** Sistema híbrido de Automação Robótica de Processos (RPA) e Copiloto com IA Generativa (Google Gemini) para o portal legado **TOTVS RM Educacional**, com gerenciador de janelas *Split-Screen 50/50* nativo no Windows (`user32.dll` P/Invoke C# + Chrome DevTools Protocol) e compilação standalone (`.exe`).
2. **[`02-pequim-engenharia-erp`](./projetos/02-pequim-engenharia-erp)** — **Sistema ERP / FSM Pequim Engenharia:** Aplicação corporativa em **React 18 + TypeScript + Tailwind CSS** com 3 módulos sincronizados em tempo real (*Coordenação/Engenharia*, *Agenda Móvel de Campo* e *Portal do Cliente*), calculadora automática de climatização/PMOC e gerador de Proposta A4/PDF.
3. **[`03-simulador-cnsd-saas`](./projetos/03-simulador-cnsd-saas)** — **Simulador CNSD & Arena Olímpica:** Plataforma SaaS Full-Stack em **Next.js 16 + React 19 + TypeScript + Firebase Firestore** para aplicação de simulados digitais, importação massiva via CSV (`writeBatch`), relatórios em PDF (`jsPDF`) e gestão de Olimpíadas Científicas.
4. **[`04-plataforma-fisica-ia`](./projetos/04-plataforma-fisica-ia)** — **PlataformaFísica (v1.2):** Ambiente adaptativo de avaliação com geração de questões inéditas via **Google Gemini API**, monitoramento anti-cola via `Page Visibility API` e exportação de pautas multi-aba em Excel (`SheetJS`).
5. **[`05-diario-escolar-ocr-vision`](./projetos/05-diario-escolar-ocr-vision)** — **Diário Escolar Inteligente (`DIARIO`):** Web App com **OCR Multimodal (`Gemini 2.5 Flash Vision`)** que extrai tabelas de horários a partir de fotos/prints e cruza automaticamente com matrizes curriculares em Node.js e Python (`pandas`).
6. **[`06-robo-totvs-universal`](./projetos/06-robo-totvs-universal)** — **Robô Universal TOTVS (`FALTAS`):** Motor RPA modular estruturado em 6 fases com Puppeteer e documentação arquitetural completa em Mermaid.js.
7. **[`07-ava-cientifico-micro-saas`](./projetos/07-ava-cientifico-micro-saas)** — **AVA Científico & Oficina PhET:** Protótipo UI/UX de alta fidelidade em **Next.js 16 + Tailwind CSS 4** com gráficos matemáticos e físicos programados em código SVG vetorial puro.

